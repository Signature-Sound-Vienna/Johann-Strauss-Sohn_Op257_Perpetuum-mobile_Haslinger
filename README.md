# Johann Strauss Sohn: „Perpetuum mobile“ Op. 257 for piano two hands

This repository contains an MEI encoding of *Perpetuum mobile*, Ein musikalischer Scherz für Orchester, Op. 257 by Johann Strauss Sohn (Johann Strauss junior) for two-hands piano, following the first edition by Haslinger, n.d. [1861],  Plate C.H. 12605. IMSLP 261356.
